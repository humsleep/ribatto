# 출시 · 홍보 전략

## 0. 냉정한 전제

경쟁자는 **구독제 고가 앱**이다 — SwingVision 연 $179.99, PB Vision 연 $180~396.
Vollio은 그들과 같은 "AI 분석 앱"으로 경쟁하면 진다(스탯·라인콜·코칭이 없다).
**"경기 영상 → 릴스용 클립"** 이라는 한 가지 일을 가장 빠르고 싸게 하는 도구로 포지셔닝해야 한다.

> 한 줄 포지셔닝: **"구독 없이, 폰 안에서, 경기 끝나고 1분이면 릴스가 나온다."**

## 1. 출시 전 (2~4주)

가장 중요한 건 광고가 아니라 **증거 영상**이다. 스탯이 아니라 결과물로 설득해야 한다.

- [ ] **비포/애프터 영상 5개 제작** — "30분 경기 → 12개 랠리 → 하이라이트 1분"을
      화면 녹화로 보여주는 15~30초 클립. 이게 모든 채널의 핵심 자산이다
- [ ] 종목별로 하나씩: 테니스 / 배드민턴 / 피클볼 / 파델 (각 커뮤니티 공략용)
- [ ] 랜딩 페이지 1장 (앱 소개 + 영상 + App Store 링크). GitHub Pages로 충분
- [ ] 개인정보 처리방침 URL 공개 ([APP_STORE.md](APP_STORE.md)에 초안)
- [ ] TestFlight로 지인 5~10명 베타 — **출시 첫날 리뷰 5개**를 확보하는 게 목적
- [ ] 인스타/틱톡 계정 개설 후 미리 3~5개 영상 업로드 (빈 계정으로 출시하지 말 것)

## 2. ASO — 무료 유입의 핵심

인디 앱 다운로드의 대부분은 스토어 검색에서 온다. 유료 광고보다 ASO가 ROI가 높다.

- **이름**: `Vollio` (짧고 브랜드형)
- **부제(30자)**: `Rally clips for racket sports` — 종목 범위를 여기서 드러낸다
- **키워드 필드(100자, 쉼표만, 공백 없이)**:
  `tennis,badminton,pickleball,padel,rally,highlight,clips,reels,shorts,editor,trim,match,video`
  - 이름·부제에 이미 쓴 단어는 키워드 필드에 **반복하지 말 것** (자동 조합됨)
- **스크린샷 첫 2장이 전환의 80%** — `ios/Marketing/`의 1·2번(30분→랠리, 공유 준비)을 앞에 배치
- **미리보기 영상(App Preview) 15~30초**를 꼭 넣는다. 이 앱은 "결과물"이 전부라 영상 유무가 크게 갈린다
- 출시 후 2~4주 간격으로 부제·스크린샷 문구를 바꿔가며 전환율 비교

## 3. 출시 주 (집중 1주)

같은 주에 몰아서 해야 스토어 알고리즘의 신규 앱 평가 구간을 탄다.

| 채널 | 무엇을 | 주의 |
|---|---|---|
| Reddit | r/tennis, r/badminton, r/Pickleball, r/padel, r/10s | **홍보 금지 규칙 확인 필수**. "만들어봤어요 + 결과 영상" 형식으로, 링크는 댓글에 |
| 한국 커뮤니티 | 테니스·배드민턴 네이버 카페, 동호회 단톡방 | 카페는 광고 규정이 엄격 — 후기 형식으로 |
| 인스타/틱톡 | 종목 해시태그 + 결과 영상 | 앱 홍보보다 "랠리 영상" 자체로 노출을 먼저 얻는다 |
| Product Hunt | 출시일 화요일~목요일 | 스포츠 앱은 반응이 크지 않으니 기대치는 낮게 |
| 지역 클럽 | 코치·동호회 총무에게 직접 | 전환율이 가장 높은 채널. 무료 프로모 코드 배포 |

**프로모 코드**: App Store Connect에서 버전당 100개까지 무료 발급된다.
인플루언서·코치·리뷰어에게 뿌리는 데 쓴다.

## 4. 가격 전략

- 출시가 **US$2.99 (한국 약 ₩4,400)** 유지. 인상보다 인하가 훨씬 어렵다
- 출시 첫 주 한정 **무료 체험 확대**(무료 5개)를 고려 — 리뷰 확보가 가격보다 중요
- 6개월 뒤 데이터를 보고 판단:
  - 전환율이 낮다 → 무료 한도를 늘리고 Pro 가치를 더 키운다
  - 전환율이 높다 → ₩5,500까지 인상 여지

## 5. 첫 3개월 목표 (현실적인 숫자)

인디 유료 앱의 초기 유입은 크지 않다. 목표는 매출이 아니라 **리뷰와 검색 순위**다.

- 1개월: 다운로드 200~500, 리뷰 10개 이상, 별점 4.5+
- 3개월: 배드민턴/피클볼 키워드 검색 상위 노출, 다운로드 1,000+
- 리뷰 요청은 **하이라이트 합본을 처음 만든 직후**에 띄우는 게 가장 효과적
  (아직 미구현 — `SKStoreReviewController` 한 줄이면 된다)

## 6. 차별화를 지킬 것

경쟁사가 따라 하기 어려운 우리만의 축은 세 가지다. 마케팅 문구를 여기에 집중한다.

1. **구독 없음** — 경쟁사 연 24만원 vs 4,400원 1회
2. **업로드 없음** — 6GB 영상을 올릴 필요가 없다. 오프라인·프라이버시
3. **배드민턴** — 아시아 최대 라켓 스포츠인데 전용 하이라이트 앱이 사실상 없다.
   테니스로 정면승부하지 말고 **배드민턴에서 1등**을 먼저 먹는 게 현실적이다
