# 직접 테스트하기 (출시 전 최종 점검)

## 실행

```bash
open ios/Vollio.xcodeproj
```

Xcode에서 기기(시뮬레이터 또는 본인 아이폰)를 고르고 **⌘R**.
시뮬레이터로 실행하면 `Vollio.storekit`이 자동 적용되어 **실제 결제 없이 구매 흐름까지** 테스트된다.

> 시뮬레이터에 테스트 영상을 넣으려면: 사진 앱을 한 번 실행해 라이브러리를 초기화한 뒤,
> Finder에서 영상 파일을 시뮬레이터 창으로 끌어다 놓으면 된다.

## 1. 첫 실행 · 기본 흐름

- [ ] 온보딩 3장이 뜨고, 첫 화면에서 언어(English/한국어/日本語)를 바꿀 수 있다
- [ ] 라이브러리 상단에 `3 free imports left` 배지가 보인다
- [ ] **Import Video** → 사진에서 경기 영상 선택 → 곧바로 감지가 시작된다
- [ ] 진행 표시가 `오디오 추출 → 랠리 감지 → 클립 렌더링 n/N` 순으로 바뀐다
- [ ] 완료 후 세션 카드에 포스터·날짜·클립 수가 나온다

## 2. 감지 품질 (가장 중요)

- [ ] 잡힌 랠리가 실제 랠리인가 (오탐이 있는가)
- [ ] 놓친 랠리가 많은가 → **민감도: 민감(Loose)** 으로 바꿔 재감지
- [ ] 잡음이 섞이는가 → **민감도: 보수(Strict)**
- [ ] 클립 앞뒤 여유(앞 2초/뒤 3.5초)와 페이드 마무리가 자연스러운가
- [ ] 배드민턴·피클볼·파델 영상이 있다면 **종목**을 바꿔 재감지해 비교

터미널에서 종목·민감도 9개 조합을 한 번에 비교할 수도 있다:

```bash
cd ios && ./Tools/validate.sh ~/Movies/경기영상.mov badminton
```

## 3. 방향 · 정렬 · 하이라이트

- [ ] **Aspect: Tall** 로 바꾸면 9:16 세로로 다시 렌더링된다 (재감지는 하지 않는다)
- [ ] 정렬 시간순 / 긴 순 / 짧은 순이 즉시 반영된다
- [ ] **Create Highlight Reel** → 수 초 내 합본 완성 → 재생/공유가 된다
- [ ] 클립 탭 → 재생 → 공유 시트로 인스타·유튜브에 실제 업로드까지 해본다
- [ ] **모든 클립** 탭에서 여러 세션의 클립이 함께 보인다

## 3-1. 기록 탭 (Season)

- [ ] 이번 달 / 개인 기록 / 전체 기간 숫자가 실제 세션과 맞는다
- [ ] **내 기록 공유하기** → 카드 이미지가 만들어지고 공유 시트가 열린다
- [ ] 인스타그램 스토리·피드에 실제로 올려본다 (1080×1350, 4:5)

## 3-1. 클립 선택 · 병합 (신규)

- [ ] 세션 상세 우상단 **선택** → 클립마다 동그라미가 생긴다
- [ ] 클립을 탭하면 초록 테두리 + 체크, 선택 안 된 클립은 흐려진다
- [ ] 하단 바에 `n개 선택됨` 과 **저장 / 병합 / 삭제**
- [ ] **저장**: 고른 클립만 사진 앱에 저장된다
- [ ] **삭제**: 고른 클립만 지워지고 나머지 번호가 다시 매겨진다
- [ ] **병합**(Pro): 2개 이상 골라야 활성화 → 하나의 영상으로 합쳐져 재생·공유된다

## 3-2. 설정 적용 방식 (변경됨)

- [ ] 종목·방향·민감도를 **바꿔도 즉시 재감지되지 않는다**
- [ ] 바꾸면 `설정이 변경되었습니다 — 눌러서 적용하세요` 안내가 뜬다
- [ ] **다시 감지**를 눌러야 적용된다
- [ ] 방향만 바꿨을 때는 재감지 없이 **재렌더링만** 수행한다 (더 빠르다)

## 3-3. 스마트 세로 크롭 · 자막 (Pro)

- [ ] **방향: 세로** + **랠리 중심 잡기** 켜고 재렌더링 → 클립마다 랠리 위치에 맞게 프레임이 잡힌다
- [ ] 재생 중 화면이 좌우로 흐르지 않는다 (한 클립 안에서는 고정)
- [ ] 코트 구석에서 벌어진 랠리도 양쪽 선수가 프레임 안에 들어온다
- [ ] 무료 상태에서 누르면 "Pro 기능입니다" 안내가 뜬다
- [ ] **자막**: 문구 입력 → 드래그로 위치 이동 → 폰트·크기·스타일 변경이 렌더 결과에 그대로 반영된다
- [ ] 날짜·장소가 영상 메타데이터에서 자동으로 채워진다

## 4. 결제 (Xcode ⌘R 실행 시)

- [ ] 영상 3개를 가져오면 4번째부터 가져오기 버튼이 자물쇠로 바뀐다
- [ ] 페이월에 `US$2.99 · 한 번`(로케일에 따라 ₩4,400), `구독 아님`, 우상단 `복원`이 보인다
- [ ] **Unlock Pro** → 구매 시뮬레이션 성공 → 배지가 `PRO`로 바뀐다

> **테스트용 Pro 해제**: Debug 빌드에서는 StoreKit 상품이 없어도(Xcode 밖에서 실행 등)
> `Pro 잠금 해제`를 누르면 로컬에서 바로 Pro가 켜진다.
> 다시 무료로 돌아가려면 페이월 우상단 **구매 복원**을 누르면 된다.
> 이 동작은 `#if DEBUG` 안에 있어 **App Store용 Release 빌드에는 포함되지 않는다.**
- [ ] 기존 세션에 **"Pro 잠금 해제됨 — 다시 만들기"** 배너가 뜨고, 누르면 원본 화질로 재렌더링된다
- [ ] **전체 사진 앱에 저장** 이 동작한다 (사진 접근 허용 팝업 1회)
- [ ] **무료 상태에서 만든 클립 우하단에 `Vollio` 워터마크가 보인다**
- [ ] Pro로 바꾸고 다시 만들면 워터마크가 사라진다
- [ ] Xcode 메뉴 **Debug → StoreKit → Manage Transactions** 에서 구매를 취소하면 다시 무료로 돌아간다

## 5. 화면 크기 · 언어

- [ ] iPhone SE(작은 화면)와 iPhone Pro Max에서 글자가 잘리거나 칸이 어긋나지 않는다
- [ ] 세 언어 모두에서 라벨·버튼이 정렬을 유지한다
- [ ] 가로 회전 / 아이패드에서도 레이아웃이 깨지지 않는다

## 6. 실기기에서만 확인 가능한 것

- [ ] 30분 4K 영상 처리 시간과 발열 ([DEVICE_TESTING.md](DEVICE_TESTING.md) 참고)
- [ ] 처리 중 앱을 백그라운드로 보냈다가 복귀했을 때의 동작
- [ ] 저장 공간: 사진 앱 원본을 **참조**하므로 30분 4K를 넣어도 앱 용량이 수 GB 늘지 않는다
      (설정 → 일반 → iPhone 저장 공간 → Vollio 에서 확인)
- [ ] 사진 앱에서 원본 영상을 지우면 세션 상세에 경고가 뜨고 재감지가 막힌다

## 알려진 제약

- **워터마크는 2패스**: 무료 클립은 컷 후 CoreImage로 마크를 한 번 더 입힌다.
  그만큼 무료 렌더링이 조금 느리다 (720p라 체감은 크지 않다)
- **감지 정확도는 테니스 야외 주간 영상 1편으로만 검증됨**: 배드민턴(실내)·야간 영상은 미검증.
  실기기 테스트에서 다른 환경 영상을 꼭 넣어볼 것
- **렌더링 중 백그라운드 전환**: iOS가 앱을 정지시키면 내보내기가 멈춘다.
  화면 꺼짐은 막아두었지만, 사용자가 직접 홈으로 나가면 중단된다 (복구 로직 없음 — v1.1 과제)

> 해결됨: 원본 이중 저장(→ 사진 앱 참조로 전환), 팬 추적 크롭의 상대 선수 잘림(→ 랠리 중심 고정 크롭으로 교체)
