# 내 아이폰에서 테스트하기

시뮬레이터가 아니라 **실제 아이폰**에서 돌려보는 절차. 무료 Apple ID로 가능하며,
유료 개발자 프로그램($99/년)은 App Store 출시 때만 필요하다.

## 1. 서명 설정 (최초 1회)

1. Xcode에서 `ios/Ribatto.xcodeproj` 열기
2. 왼쪽 프로젝트 네비게이터에서 **Ribatto** (파란 아이콘) 클릭 → **TARGETS: Ribatto** 선택
3. **Signing & Capabilities** 탭:
   - **Automatically manage signing** 체크
   - **Team**: 본인 Apple ID 선택 (없으면 `Add an Account…`로 로그인)

> **이미 설정되어 있다.** 프로젝트에 `DEVELOPMENT_TEAM = 68BP5NY48R`(Hyuk Ahn)가
> Debug/Release 모두에 들어가 있어 실기기 빌드가 바로 된다.
> 다른 Apple ID로 바꾸려면 이 값을 지우고 Xcode에서 Team을 다시 고르면 된다.
>
> `Signing for "Ribatto" requires a development team` 오류가 다시 나면
> 이 값이 비어 있는 것이다. 본인 팀 ID는 아래로 확인할 수 있다:
> ```bash
> security find-certificate -a -c "Apple Development" -p | openssl x509 -noout -subject
> ```
> 출력의 `OU=` 뒤 10자리가 팀 ID다.
   - **Bundle Identifier**: `com.ribatto.app` 이 이미 누군가 쓰고 있으면 거부된다.
     `com.<본인영문이름>.ribatto` 처럼 고유하게 바꾼다.
     → 바꿨다면 `Ribatto.storekit`의 `productID` 접두사도 같이 맞추는 게 좋다.

## 2. 아이폰 연결 + 개발자 모드

> **개발자 모드는 평소 설정에 보이지 않는다.** Xcode가 기기에 한 번 접근을 시도해야
> 그때부터 메뉴에 나타난다. 그래서 순서가 중요하다.

1. 케이블(데이터 전송용)로 Mac에 연결 → 아이폰에 뜨는 **"이 컴퓨터를 신뢰하시겠습니까?"** →
   **신뢰** + 암호 입력
2. Xcode 상단 기기 목록에서 **본인 아이폰 선택 → ⌘R 실행 시도**
   - 여기서 `Developer Mode disabled` 오류가 난다. **이게 정상이다** — 이 시도가 있어야 다음 단계가 열린다
3. 아이폰 **설정 → 개인정보 보호 및 보안** → 맨 아래 **개발자 모드** → 켜기
4. **재시동** → 잠금 해제 시 "개발자 모드를 켜시겠습니까?" → **켜기** + 암호
5. Xcode에서 다시 **⌘R**

**개발자 모드가 여전히 안 보일 때**

- iOS 16 미만이면 개발자 모드 자체가 없다 → 3~4단계를 건너뛰고 바로 설치된다
- 충전 전용 케이블이면 기기가 인식되지 않는다
- 아이폰 잠금이 풀려 있어야 Xcode가 기기를 인식한다
- Xcode **Window → Devices and Simulators**에 기기가 뜨는지 먼저 확인 —
  여기 안 뜨면 연결·신뢰 단계 문제다

첫 실행 시 아이폰에 "신뢰할 수 없는 개발자" 경고가 뜨면:
**설정 → 일반 → VPN 및 기기 관리 → 본인 Apple ID → 신뢰**

> **유료 개발자 프로그램 가입 완료 상태다.** 서명된 앱은 **1년간 유효**하므로
> 7일마다 다시 설치할 필요가 없다.
>
> **이 첫 실행이 번들 ID를 애플에 등록한다.** `com.ribatto.app`을 다른 개발자가
> 이미 선점했다면 바로 여기서 오류가 난다 — 그때는 `com.본인영문이름.ribatto`처럼
> 바꾸고 `Ribatto.storekit`의 제품 ID 접두사도 함께 맞춘다.
> 즉 **기기 테스트가 번들 ID 확보를 겸한다.** 그래서 이 단계를 가장 먼저 해야 한다.

## 2-1. 내 기기에서 Pro / 무료 자유 전환 (소유자 모드)

TestFlight·App Store 빌드는 Release라 개발용 우회가 없고, 한 번 결제한 비소모품은
되돌릴 수 없다. 그래서 **본인 기기에서만 동작하는 전환 스위치**를 넣어두었다.

1. 라이브러리 왼쪽 위 **`무료 n회 남음` / `PRO` 배지를 1.2초 이상 길게 누른다**
2. 암구호 입력: **`ahn-rally-2026`**
3. 열리는 패널에서
   - **Pro 켜기** 토글 → Pro / 무료를 즉시 전환
   - **무료 횟수 초기화** → 무료 3회를 다시 채움
   - **소유자 모드 끄기** → 원래 상태(실제 구매 여부)로 복귀

> 암구호는 코드에 **SHA-256 해시로만** 들어가므로 바이너리에서 원문이 보이지 않는다.
> 바꾸려면 `PurchaseManager.ownerHash`를 아래 결과로 교체한다:
> ```bash
> printf '%s' "새 암구호" | shasum -a 256
> ```
> 길게 누르기 + 암구호 2단계라 일반 사용자가 우연히 열 수 없고,
> 열어도 암구호 없이는 아무 것도 바뀌지 않는다.

## 3. 실기기에서 꼭 확인할 것

- [ ] 4K 30분 영상 가져오기 — 소요 시간과 발열 (A17 이상에서 감지 1분 내외 예상)
- [ ] 처리 중 앱을 백그라운드로 보냈다가 복귀 (iOS가 중단시키는지)
- [ ] 저장 공간: 원본이 앱 내부로 복사되므로 30분 4K = 약 7GB가 두 번 쓰인다
      → 출시 전 "원본 복사 대신 참조" 또는 "처리 후 원본 삭제" 옵션 검토
- [ ] 공유 시트로 인스타그램 릴스/유튜브 쇼츠에 실제 업로드
- [ ] 세로 모드(Tall) 클립이 실제 릴스 화면비와 맞는지

## 4. 결제(IAP) 테스트

- **시뮬레이터/로컬**: Xcode에서 ⌘R로 실행하면 `Ribatto.storekit` 설정이 자동 적용되어
  실제 결제 없이 구매 흐름을 테스트할 수 있다 (스킴에 이미 연결돼 있음).
  Xcode 메뉴 **Debug → StoreKit → Manage Transactions**에서 구매 취소/환불도 시뮬레이션 가능.
- **실기기 샌드박스**: App Store Connect에 상품을 등록하고 Sandbox 테스터 계정으로 로그인해야 한다.
  자세한 절차는 [APP_STORE.md](APP_STORE.md) 참고.
