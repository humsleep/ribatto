# Ribatto 🎾🏸🥎

라켓 스포츠(테니스·배드민턴·피클볼·파델) 경기 영상에서 랠리를 자동 감지해
릴스/쇼츠용 세로 클립을 만들어주는 **iOS 앱**.

경기 한 판을 통째로 넣으면 랠리만 골라 클립으로 잘라준다. 서버도, 계정도,
구독도 없이 **전부 아이폰 안에서** 처리된다.

## 실행

```bash
open ios/Ribatto.xcodeproj
```

Xcode에서 시뮬레이터나 아이폰을 고르고 ⌘R. 터미널 빌드는 [ios/README.md](ios/README.md) 참고.

## 어떻게 동작하나

라켓·셔틀콕·공의 **타구음**은 종목마다 다른 주파수 대역에 몰린 짧은 트랜지언트다.
오디오를 16kHz로 뽑아 그 대역의 스펙트럼 flux가 튀는 지점을 찾고, 묶어서 랠리로 만든다.
영상 인식이 아니라 소리 인식이라 모델 다운로드도, 네트워크도 필요 없다.

26분 4K 경기 기준 **오디오 추출 1.0초 + 감지 0.1초**, 클립 렌더링 약 31초.

## 주요 기능

- **랠리 자동 감지** — 종목별 프리셋(테니스/배드민턴/피클볼/파델), 민감도 3단계
- **베스트 랠리 자동 선별** — 타구 수·환호·길이로 점수를 매겨 좋은 포인트를 앞에 세운다
- **세로 변환** — 16:9 / 9:16(릴스·쇼츠·틱톡) / 4:5(인스타 피드)
- **선수 추적** (Pro) — 한 번 지목하면 모든 세로 클립이 그 선수를 중심으로 확대·재프레이밍
- **릴스 편집** — 순서 변경, 클립별 포함/제외, 랠리별 길이 모드(전체 / 마무리만 / 훅)
- **클립별 길이 조정**, 오디오 라우드니스 정규화, 자막 번인
- 다국어 (영어 / 한국어 / 일본어)
